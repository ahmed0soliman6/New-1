# خطة التنفيذ: إضافة تنبيهات الحقول الإجبارية باللون الأحمر ومنع فقدان بيانات الموعد عند تسجيل الزيارة

تهدف هذه الخطة إلى حل مشكلة عدم وجود تنبيهات مباشرة عند نسيان اختيار "جنس المريض" أو "الاسم" أو "نوع الزيارة" في شاشة تسجيل الزيارة (`PatientIntakeScreen.tsx`)، وضمان عدم اختفاء الموعد أو مسح البيانات عند وجود خطأ أو عدم اكتمال البيانات.

---

## 1. تحليل المشكلة والحل الهيكلي
- **السبب**: عند تحويل موعد "حضر المريض" إلى شاشة تسجيل الزيارة، لم تكن هناك حدود أو تنبيهات حمراء مباشرة بجوار حقول (اسم المريض، الجنس/النوع، نوع الزيارة). وكان النموذج يطلق تنبيهاً كلاسيكياً أو يكتفي بالـ Alert، بينما البيانات المبدئية قد تضيع إذا حدُث خطأ في عملية الحذف/التسجيل.
- **الحل الهيكلي**:
  1. إضافة حالة أخطاء مباشرة للنموذج (`errors: Record<string, string>`).
  2. التحقق الصارم عند الضغط على "تسجيل الزيارة وطباعة التذكرة":
     - **اسم المريض** (إجباري): إظهار خط أحمر حول الصندوق مع رسالة توضيحية تحته.
     - **النوع / الجنس** (إجباري): إظهار إطار أحمر حول زرّي (ذكر / أنثى) مع رسالة توضيحية تحتهما.
     - **نوع الزيارة** (إجباري): إظهار إطار أحمر ورسالة تحذيرية.
  3. التمرير التلقائي الفوري (Smooth Scroll) إلى أول حقل يحتوي على خطأ.
  4. **حماية الموعد من الضياع**: عدم مسح البيانات المبدئية `initialData` أو الموعد إلا بعد التأكيد الناجح التام للعملية وسحب التذكرة، لضمان عدم اختفاء الموعد إطلاقاً.

---

## 2. خطوات التنفيذ التفصيلية

### الخطوة 1: تحديث حالة التحقق في `PatientIntakeScreen.tsx`
- إضافة حالة `formErrors`:
  ```ts
  const [formErrors, setFormErrors] = useState<{
    name?: string;
    gender?: string;
    visitType?: string;
  }>({});
  ```
- تحديث `handleSubmit`:
  - التحقق من `name`:
    ```ts
    if (!name.trim()) errors.name = 'يرجى إدخال اسم المريض ثلاثياً أو رباعياً';
    ```
  - التحقق من `gender`:
    ```ts
    if (!gender || (gender !== 'male' && gender !== 'female')) {
      errors.gender = 'يرجى تحديد جنس المريض (ذكر / أنثى)';
    }
    ```
  - التحقق من `selectedVisitType`:
    ```ts
    if (!selectedVisitType?.name) {
      errors.visitType = 'يرجى تحديد نوع الكشف أو الزيارة';
    }
    ```
  - إذا وجدت أخطاء:
    - إيقاف الإرسال وعدم مسح الموعد أو البيانات المبدئية.
    - إظهار شريط تحذيري باللون الأحمر أعلى النموذج.
    - التمرير التلقائي لحقل الخطأ.

---

### الخطوة 2: إضافة الواجهات المباشرة للأخطاء (Inline Field-Level Red Errors)
- **صندوق اسم المريض**:
  - إضافة حدود حمراء `border-rose-500 focus:ring-rose-500` ورسالة تنبيه إيقونية تحته مباشرة.
- **قسم النوع / الجنس (ذكر / أنثى)**:
  - إضافة إطار أحمر بارز `border-2 border-rose-500 bg-rose-500/5` حول أزرار الاختيار ورسالة تنبيه إيقونية تحتهما مباشرة.
- **قسم نوع الزيارة / الكشف المتاح**:
  - إضافة إطار أحمر ورسالة تنبيه إيقونية تحته عند عدم الاختيار.
