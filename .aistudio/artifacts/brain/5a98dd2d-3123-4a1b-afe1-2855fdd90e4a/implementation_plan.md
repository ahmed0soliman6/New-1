# خطة تنفيذ: محرك البحث السريري الذكي المزدوج وتطوير البطاقات الطبية الأربعة

بناءً على متطلباتك الدقيقة والردود التوضيحية والصور المرفقة، توضح هذه الخطة خطوات بناء وتحديث **البطاقات السريرية الأربعة** في شاشة الكشف الطبي (`ExaminationScreen.tsx`) وإدارة الأدلة الطبية (`MedicalCatalogsManager.tsx` في الإعدادات):
1. **بطاقة الروشتة الدوائية الإلكترونية (Rx Medications Card)**
2. **بطاقة المعامل والتحاليل الطبية (Laboratory Tests Card)**
3. **بطاقة الأشعة والتصوير الطبي (Radiology & Medical Imaging Card)**
4. **بطاقة التشخيصات السريرية (Clinical Diagnoses - ICD-10 Card)**

---

## 1. المعايير الهندسية والأمنية المعتمدة
- **محرك بحث هجين متكامل (Hybrid Search Engine)**:
  1. البحث أولاً في **دليل العيادة المحلي ("دليلي")** مع أولوية الظهور وشارة `من دليلي ✓`.
  2. البحث في **الأرشيف الطبي القياسي والمصري المدمج** مع شارة `الأرشيف 🇪🇬` وزر حفظ مباشر `+ حفظ في دليلي`.
  3. **الربط الحي المعتمد (Live API Integration)**:
     - استخدام NLM ClinicalTables API رسمي للتشخيصات (`ICD-10-CM`) والتحاليل (`LOINC / Clinical Lab Tests`).
     - **منع توليد أي بطاقات وهمية تماماً**: إزالة الكود المولد للبطاقات الوهمية (مثل `(نتيجة البحث في الأرشيف المصري Online)`) التي ظهرت في لقطة الشاشة.
- **تخزين مؤقت في المتصفح (Client-side Caching)**:
  - بناء وحدة كاش محلية خفيفة (`localStorage / memory cache`) لنتائج استعلامات الـ API، بحيث لا يُعاد طلب السيرفر أو استهلاك الكوتة لنفس الكلمة أو المصطلح مطلقاً.
- **دعم ثنائي اللغة والنطق الصوتي والاختصارات الطبية (Phonetic & Bilingual Engine)**:
  - دعم كتابة الاختصارات الطبية بالإنجليزية ونطقها بالحروف العربية (مثل: `CBC` ⟷ `سي بي سي` / `تراكمي`، `CXR` ⟷ `سي اكس ار` / `اشعة صدر`، `HTN` ⟷ `ضغط` / `اتش تي ان`).
  - دعم الأدوية المصرية بالاسم التجاري والعلمي والشكل الصيدلي والتركيز.
- **التوافق مع تجربة المستخدم (UI/UX - Zero-Pill & Clear Layout)**:
  - شريط بحث بارز مع زر مسح `✕` وزر `+ إضافة` عند الضغط على Enter أو النقر.
  - قائمة منسدلة سريعة مجمعة بـ `<optgroup>` ("فحوصات دليلي" و "الأرشيف الطبي القياسي").
  - بطاقات نتائج أنيقة بخط أحادي `font-mono` للرموز الطبية والأسماء الإنجليزية، مع تفادي الحشو والبطاقات المتداخلة.

## 2. مراحل التنفيذ التفصيلية

### المرحلة 1: بناء وحدة الأرشيف الطبي القياسي ومحرك البحث والتطبيع الصوتي
- إنشاء ملف مستقل مركزي: `/src/data/medicalStandardArchive.ts`:
  - **قاعدة بيانات الأدوية المصرية الشائعة (EDA Comprehensive)**: تشمل أشهر 70+ دواء مصري متداول ومسجل بالاسم التجاري (عربي وإنجليزي)، الاسم العلمي، الشكل الدوائي، التركيز، التصنيف، الجرعة الافتراضية، المدة، والتوقيت.
  - **قاعدة بيانات التحاليل الطبية الشاملة (Lab Archive)**: تشمل جميع التحاليل الشائعة مع اختصاراتها الطبية (`CBC, HbA1c, FBS, PPBS, RBS, KFT, LFT, ALT, AST, TSH, FT3, FT4, ESR, CRP, PT, INR, D-Dimer, Troponin, PSA, UACR, Urine RE, Stool RE...`) ونطقها الصوتي وأسمائها بالعربية والإنجليزية والقيم المرجعية ونوع العينة.
  - **قاعدة بيانات الأشعة والتصوير الطبي (Radiology Archive)**: تشمل فحوصات الأشعة الشائعة (`CXR, US, CT, HRCT, MRI, MRCP, Echo, ECG, Holter, Doppler, KUB, DEXA, Mammogram...`) وأسماؤها واختصاراتها بالعربية والإنجليزية ونوع الجهاز/التقنية.
  - **قاعدة بيانات التشخيصات السريرية (ICD-10 Clinical Archive)**: تشمل أكواد ICD-10 المعتمدة وأشهر الأمراض الباطنية والمزمنة والجراحية واختصاراتها (`HTN, DM, T2DM, GERD, IBS, IHD, CAD, ACS, MI, HF, AF, COPD, BA, UTI, CKD, Gout, OA, IDA...`) بالعربية والإنجليزية.
- **محرك التطبيع الصوتي واللغوي (Phonetic & Bilingual Normalizer)**:
  - إزالة التشكيل وتوحيد الحروف (أ/إ/آ -> ا، ة -> ه، ى -> ي).
  - مصفوفة مطابقة صوتية ذكية (تطابق الاختصارات الإنجليزية ونطقها المعرب مثل `سي بي سي` ⟷ `CBC`).

### المرحلة 2: محرك البحث الهجين والربط الخارجي مع التخزين المؤقت (Client Caching)
- إنشاء ملف مساعدة للبحث والخدمات: `/src/services/clinicalSearchService.ts`:
  - إدارة البحث الهجين متدرج الأولويات:
    1. **دليلي (My Clinic Catalog)**: الأولوية القصوى (مطابقة فورية).
    2. **الأرشيف المدمج (Standard Archive)**: أولوية ثانية فورية بدون أي تأخير شبكة.
    3. **الربط الخارجي الحي (NLM ClinicalTables API)** للتحاليل والتشخيصات عند عدم كفاية النتائج المحلية، مع `AbortController` لإلغاء الطلبات المتداخلة.
  - **آلية التخزين المؤقت (Client-side Search Cache)**:
    - تخزين نتائج الاستعلامات في `localStorage` مع مفتاح منسق (مثل `soli_api_cache_icd10_{query}`) مع حد أقصى للذاكرة وانتهاء صلاحية (TTL)، لمنع تكرار أي استدعاء خارجي للكلمة نفسها والحفاظ على الكوتة.
  - **حذف وتصفية أي توليد عشوائي أو بطاقات وهمية (Anti-Hallucination Guard)**:
    - لن تظهر أي نتيجة ما لم تكن مستندة إلى إدخال حقيقي في "دليلي" أو الأرشيف المصري الموثق أو رد API معتمد.

### المرحلة 3: تحديث وتطوير البطاقات السريرية في شاشة الكشف (`ExaminationScreen`)
- **تحديث `MedicationsCard.tsx`**:
  - إزالة الكود المولد للبطاقات الوهمية Online نهائياً.
  - تفعيل البحث المزدوج في دليلي والأرشيف المصري المدمج.
  - شريط البحث البارز مع زر الحذف `✕` وزر `+ إضافة` (الذي يفتح نافذة إضافة الدواء للزيارة الحالية فقط مع خيار حفظه في دليلي إذا رغب الطبيب).
  - القائمة المنسدلة المجمعة `<optgroup>` ("أدوية دليلي" / "أدوية الأرشيف المصري").
  - بطاقة النتيجة: الاسم التجاري بالعربي والإنجليزي، المادة الفعالة، الشكل الدوائي، شارة المصدر، وزر `+ حفظ في دليلي` بنقرة واحدة إذا كان من الأرشيف.
  - تعبئة الجرعة والمدة والتوقيت الافتراضي تلقائياً عند الاختيار، مع بقائها قابلة للتعديل الفوري من الطبيب.

  - القائمة المنسدلة المجمعة `<optgroup>` ("تحاليل دليلي" / "الأرشيف المخبري").

  - بطاقات النتائج مع توضيح التقنية وشارة المصدر وخيار الحفظ في دليلي.
- **تحديث `DiagnosisCard.tsx`**:
