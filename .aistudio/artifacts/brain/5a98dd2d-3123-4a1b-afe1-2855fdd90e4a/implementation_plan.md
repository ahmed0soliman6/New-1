# الخريطة التفاعلية المستقلة لنظام العيادة (Soli Medical Interactive Architecture & Explainer HTML)

تم إنشاء ملف HTML التفاعلي المستقل (`public/soli-medical-architecture.html`) وإتاحة تحميله ومعاينته مباشرة من **إعدادات النظام (البند 10: النسخ الاحتياطي السحابي وتصدير البيانات)**:

1. **4 منظورات تفاعلية متكاملة باللغة العربية:**
   - **01. دورة المريض التشغيلية (`Workflow`):** تتبع المسار الكامل من الحجز والاستقبال حتى الطابور، الكشف، الروشتة، والتقارير.
   - **02. البنية المعمارية والأمان (`Architecture`):** تفاعل الواجهة مع المعاملات الذرية (`firestoreWorkflows`)، ترشيد القراءات (`READ_OPT`)، قواعد `firestore.rules`، ووظائف السحابة (`Cloud Functions`).
   - **03. مخطط علاقات قاعدة البيانات (`ERD 16 Collections`):** جميع المجموعات الـ 16 وحقولها ومفاتيح الربط (`patientId`, `visitId`, `invoiceId`, `dayKey`).
   - **04. الدليل التشغيلي التفاعلي (`Explainer`):** شرح مهام الطبيب، الاستقبال، ومدير النظام مع الانتقال الفوري وإضاءة المسار المرتبط بكل خطوة.
2. **أدوات استكشاف ومشاركة مستقلة:**
   - فاحص جانبي (`Source & Schema Inspector`) يعرض اسم الملف والدالة البرمجية والحقول لكل عقدة.
   - فلترة تتبع المسار (`Upstream` / `Downstream` / `المسار المتصل`)، بحث فوري (`/`)، تبديل الوضع النهاري/الليلي (`T`)، وزر تحميل نسخة HTML المستقلة للعمل بدون إنترنت.
